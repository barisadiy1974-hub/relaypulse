Bought it on one device? Unlock the other

The purchase belongs to your Apple Account, not to one device, so it unlocks RelayPulse on both your iPhone and your Mac. On the device you did not buy on:

  1. Install RelayPulse from the App Store and open it.
  2. iPhone: Settings → License → Restore Purchases.
    Mac: Settings → General → Restore Purchases — or on the Unlock screen, Restore Purchase.
  3. If you are asked, sign in with the same Apple Account you bought with.
  4. It unlocks within a few seconds: the iPhone shows RelayPulse Lifetime, the Mac shows Unlocked — unlimited servers.

Still locked? Check that both devices use the same Apple Account for App Store purchases (iPhone: Settings → your name → Media & Purchases; Mac: App Store → Account), then tap Restore again. Nothing is charged twice — restoring never buys anything.

Phone apps need the agent port: TCP 19191

Windows, Linux, Mac, iPhone and Android all read your servers through the RelayPulse HTTPS agent on port 19191. If a firewall blocks it, the desktop quietly falls back to SSH — but a phone has no SSH login, so it shows "Timed out".

1. Open it on every server (as root):

ufw allow 19191/tcp

2. Open it at your VPS provider too. Many providers have a firewall in their web panel that sits in front of the server. Allow incoming TCP 19191 there as well — ufw can't change that one.

3. Check it. In the app, the server card turns green and shows the agent as the source.

Is it safe to open? Yes. The agent answers only requests that carry that server's own random token, it is read-only (CPU, memory, traffic and service status), it cannot run commands, and the apps pin its certificate on first contact so the token is never sent to anyone else.
